# Python 學習平台需求規格書

版本：0.1（內部測試版）  
目標學校：聖若瑟教區中學第五校  
目標使用者：初三及高中學生、教師、管理員  
首輪容量：40 人同時在線  
首輪環境：Apple Silicon macOS + Docker，本地部署

## 1. 產品目標

建立一個校內使用的中英雙語 Python 學習平台，支援教師課堂示範、學生即時練習、課後自學和功課。平台整合教材、瀏覽器編程、自動批改、AI 引導、即時課堂、學習分析和遊戲化功能，學生無須安裝 Python。

第一版先完成可內部測試的核心教學流程；AI 生成教材、進階評分、完整遊戲化、即時課堂進階工具和專題展示於後續版本逐步完善。

## 2. 使用者與權限

### 2.1 管理員

- 建立及管理教師、學生帳戶、班別和全域設定。
- 批量匯入學生名單。
- 重設教師或學生密碼。
- 設定 AI 供應商、API 金鑰、模型、全校及個人用量上限。
- 設定 AI 提示策略、答案顯示規則、對話保存期限及是否保存對話。
- 設定遊戲化、排行榜、備份、檔案大小、可用 Python 套件等開關。
- 查看登入、設定、成績和內容修改的稽核紀錄。

### 2.2 教師

- 建立及管理自己的課程、單元、教材、練習和功課。
- 把整個班別加入課程，或建立課程代碼讓學生加入。
- 批量建立學生；重設所教學生的密碼。
- 使用共用教材庫及題庫，複製課程，匯入／匯出內容。
- 建立評分準則、公開及隱藏測試案例，覆核 AI 建議分數並手動改分。
- 查看所教學生的進度、作答歷程、AI 使用、學習時間及分析報表。
- 發布公告、站內／電郵通知及即時課堂活動。

### 2.3 學生

- 使用學號及密碼登入，首次登入須更改初始密碼。
- 透過班別分配或課程代碼加入課程。
- 閱讀／播放／下載教材、完成練習及功課、上傳專題檔案。
- 在瀏覽器內編寫和執行 Python，取得自動批改結果及 AI 提示。
- 查看自己的當前課程、分數、回饋、徽章和學習進度。
- 離開班別後不在學生介面保留歷年課程資料；相關教務資料按校方政策封存或刪除。

## 3. 內容架構

內容層級為：`班別 → 課程 → 單元 → 教材／練習／功課`。

- 教材支援 PPT、PPTX、PDF、Word、圖片、影片連結、CSV、Python 檔案及 ZIP。
- PPT／PPTX 須支援保留原檔下載、網站內播放、轉成網頁教材，以及 AI 摘要、翻譯和產生練習。
- 教師編輯器同時支援視覺化編輯、Markdown、數學公式、程式碼區塊、圖片和影片嵌入。
- AI 生成或翻譯的內容必須經教師預覽及確認後才可發布。
- 上傳大小限制由管理員設定。

## 4. 題型與作業

### 4.1 題型

- 選擇題
- 填充題
- 簡答題
- 程式填空
- 完整 Python 編程題
- 檔案上傳
- 小型專題（檔案提交及教師評分）

### 4.2 作業設定

- 發布及截止時間、逾期提交、補交及重新提交。
- 限制作答次數、隨機排列題目、按學生抽取不同題目。
- 教師設定公布標準答案及完整解答的時間。
- 學生提交後立即看到分數和測試結果。

### 4.3 評分

- 選擇題及填充題自動批改。
- 簡答題由 AI 建議分數及評語，教師確認後才計入成績。
- 上傳檔案及專題由教師評分。
- 程式題按測試輸出、程式碼品質、指定概念、效率和 AI 綜合評語評分。
- 教師可建立自訂評分準則及權重，並手動覆核或改分。
- 測試案例分為公開與隱藏；公開案例顯示輸入、預期及實際結果，隱藏案例只顯示通過／失敗。

## 5. Python 編程環境

- 在瀏覽器內提供編輯、執行、自動儲存和提交功能。
- 支援基本 Python 及由教師／管理員允許的 NumPy、Pandas、Matplotlib 等套件。
- 學生不可自行安裝套件，執行環境不可連接外部網絡。
- 每次執行須限制 CPU 時間、牆鐘時間、記憶體、輸出大小和檔案系統範圍。
- 每次執行使用隔離的臨時環境，完成後清除。
- 保存程式碼版本、執行、提交、測試結果和貼上事件，供教師查看。
- 平板及手機可閱讀內容和進行基本編輯；桌面裝置提供最佳編程體驗。

## 6. AI 功能

- 供應商中立：管理員可設定 API 金鑰、模型、全校／每名學生用量及每日限額。
- AI 助教可由管理員設定為只給逐步提示，或在指定嘗試次數後提供較完整協助。
- AI 可分析學生程式、指出錯誤方向、提出下一步問題，但是否直接顯示答案由管理員控制。
- 支援教材摘要、內容翻譯、題目生成、簡答評分建議、程式碼品質評語和常見錯誤歸納。
- AI 產生的教材、題目、翻譯、評語及成績建議全部須由教師確認。
- AI 對話預設保存並供任課教師查看；管理員可設定保存期限或停用保存。
- 不把學生姓名等非必要個人資料傳送給 AI；記錄模型、用量、延遲和錯誤，但不在一般日誌保存 API 金鑰。

## 7. 即時課堂與遊戲化

### 7.1 即時課堂

- 教師即時發布題目或活動、查看全班完成進度。
- 展示匿名答案、鎖定活動、控制開始／結束時間。
- 提供適合投影的教師畫面。

### 7.2 遊戲化

- 經驗值、徽章、連續學習紀錄、關卡地圖、虛擬獎勵和班內排行榜。
- 管理員可逐項開關；排行榜可完全隱藏。

## 8. 學習分析與報表

- 每名學生的完成率、分數、作答次數和學習時間。
- 每題正確率、常見錯誤、公開／隱藏測試通過情況。
- AI 提示次數、用量及對話；編程嘗試、貼上和修改歷程。
- 班別及課程比較。
- 匯出 Excel／PDF 成績表和分析報告。
- 學生只可查看自己的資料；教師只可查看所教班別；管理員可按權限查看全校資料。

## 9. 通知、語言及介面

- 支援站內通知、教師公告和電郵通知。
- 通知情境包括功課發布、截止提醒、補交通知、批改完成及公告。
- 網站介面支援繁體中文／英文即時切換。
- 教師可提供中英文教材；AI 可產生待教師確認的翻譯版本。
- 支援 Windows、macOS、Chromebook、iPad／平板及手機；所有主要頁面採響應式設計。
- 視覺品牌參考學校網站及校徽，最終風格於原型階段確認。

## 10. 防作弊、保安及私隱

- 程式碼相似度檢查、貼上事件紀錄、考試模式和 AI 助教停用開關。
- 考試模式可限制查看教材、答案、提示及其他平台頁面；瀏覽器切頁只能記錄及提示，不能視為絕對防作弊機制。
- 密碼使用強雜湊；首次登入必須改密碼；教師／管理員可重設。
- 所有權限於伺服器端驗證，不依賴前端隱藏按鈕。
- 防止學生互相讀取答案、提交、檔案、AI 對話及隱藏測試案例。
- 檔案上傳須驗證類型、大小、擁有者及下載權限。
- API 金鑰加密保存，介面只顯示遮罩值。
- 記錄登入、權限、內容、成績、AI 設定和備份操作。

## 11. 備份與資料生命週期

- 每日自動備份可由管理員開關，並可設定保留份數或天數。
- 備份涵蓋資料庫、上傳檔案和必要設定，不包含可重新建立的暫存執行環境。
- 管理員可手動建立備份並執行還原驗證。
- 學生離班後不在學生介面保留歷史內容；實際刪除或封存依校方政策執行並留下稽核紀錄。

## 12. 分階段範圍

### MVP／內部測試版

- 三類帳戶、登入、首次改密碼、班別及課程管理。
- Excel／CSV 匯入學生、班別加入及課程代碼。
- 課程、單元、教材上傳／播放／下載。
- 基本題型、作業時限、提交和基本成績。
- 瀏覽器 Python 編輯、隔離執行、公開／隱藏測試及自動批改。
- 基本 AI 提示及管理員用量設定。
- 教師進度、成績和基本分析頁。
- 站內通知、基本稽核、手動／排程備份設定。

### 第二階段

- PPT 轉網頁、AI 摘要／翻譯／練習生成。
- AI 簡答及進階程式碼評分工作流。
- 完整即時課堂、遊戲化、排行榜及共用題庫。
- 進階防抄襲、考試模式、完整 Excel／PDF 報表和電郵通知。
- 專題提交、內容版本管理及更多營運設定。

## 13. 內部測試驗收標準

1. 40 人同時使用時，可穩定登入、瀏覽教材、執行程式和提交功課。
2. 教師可即時看到班別進度和提交結果。
3. AI 用量可按全校及學生限制，API 金鑰不暴露給學生。
4. 學生不能查看其他學生答案、隱藏測試、教師草稿或未公布解答。
5. 公開／隱藏測試、立即回饋和答案定時公布符合設定。
6. 管理員可啟用備份並成功完成至少一次還原演練。
7. 主要流程可在 Windows／macOS／Chromebook／iPad 及手機瀏覽器使用。
8. 關鍵帳戶、權限、內容、成績和 AI 設定操作均有稽核紀錄。
9. 本地 Docker 在 Apple Silicon macOS 可重複啟動，資料於容器重啟後仍保留。
