Host and WSL
------------
- Windows 11 Home, x64.
- WSL version 2.6.3.0; default WSL version 2.
- `wsl -l -v` shows only the `docker-desktop` distro, running as WSL2.

Docker Desktop managed daemon

- The Windows Docker CLI reaches the `desktop-linux` managed daemon.
- Registered runtimes include `runc`, `io.containerd.runc.v2`, and an NVIDIA

- The daemon's default runtime is `runc`.
- A local `--runtime=runsc` probe already failed with
  `unknown or invalid runtime name: runsc`.

Conservative result
-------------------

controlled Linux-owned Docker/containerd host for this security gate. The
current machine cannot prove a supported real gVisor/runsc runtime. Do not
inject binaries or configuration into Docker Desktop's private VM, and do not
implement the production StrongExternalExecutor before the runtime gate passes.
