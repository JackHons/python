## 關鍵缺口

1. `db/index.ts` 的資料庫入口主要面向 D1 binding；需要一個可測試的本地 SQLite connection／migration／transaction／foreign-key factory。
2. 尚未見完整伺服器端登入、session、password reset、RBAC scope query、CSV／Excel import API。
3. 尚未見教材／檔案安全下載、PPT 轉換 job、題庫、作業規則、提交 snapshot 及教師評分 API。
4. Runner `/execute` 尚未與 `submission_answers`、不可變 code snapshot、test results、grade release 整合。
5. 尚未見 vendor-neutral AI、加密 key、原子 quota reservation、保存期限與教師 review 狀態機。
6. 尚未見即時課堂、站內／電郵通知、分析／Excel／PDF、audit、backup／restore 服務。
7. 前端仍以原型互動為主；需要 typed API client、loading／error／empty state、server session 及端到端資料流程。

## P1 風險安排

| 風險 | 最早處理 phase | 必須證明 |
| --- | --- | --- |
| SQLite foreign keys 未在每個 runtime connection 啟用 | P1 | connection factory、pragma、foreign key negative test、`foreign_key_check` |
| `submission`／`question`／`assignment_item` 關係及抽題後改題 | P2 | transaction、固定 `submission_answers` snapshot、併發／刷新不變 |
| `code_snapshot`／`code_run` 關係被重試覆寫 | P3 | append-only run、snapshot hash、submission answer foreign key |
| hidden test input／expected／weight／trace 泄漏 | P3 | server projection、學生 API／HTML／log 負向測試 |
| AI quota 非原子而被併發超額 | P4 | conditional upsert／reservation／settlement／rollback 壓測 |
