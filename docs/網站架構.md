# Python 學習平台網站架構

## 1. 導覽架構

### 學生端

- 儀表板：今日課堂、待交功課、學習進度、最近通知。
- 我的課程：課程 → 單元 → 教材／練習／功課。
- 編程工作台：題目、編輯器、執行輸出、測試結果、AI 助教。
- 成績與進度：分數、完成率、徽章及教師回饋。
- 通知與個人設定：語言、密碼及介面偏好。

### 教師端

- 教師儀表板：今日課堂、待批改、班別概況、常見錯誤。
- 班別與學生：名單匯入、密碼重設、學生進度。
- 課程工作室：課程／單元／教材／題目／功課編輯。
- 即時課堂：發布、鎖定、匿名展示及全班進度。
- 批改中心：簡答、上傳檔案、專題及 AI 建議覆核。
- 分析與報表：學生、題目、班別、AI 使用及匯出。
- 共用資源庫：教材、題庫、複製及匯入／匯出。

### 管理員端

- 系統概況：在線人數、執行佇列、儲存及 AI 用量。
- 帳戶與權限：管理員、教師、學生和班別。
- AI 設定：供應商、模型、金鑰、限額和提示政策。
- Python 執行設定：套件白名單、時間、記憶體和輸出限制。
- 功能開關：遊戲化、排行榜、AI 對話、電郵及備份。
- 稽核、備份與系統健康。

## 2. MVP 主要流程

### 建班與入學

1. 管理員建立教師帳戶。
2. 教師或管理員以 Excel／CSV 匯入學生。
3. 系統建立班別和初始密碼。
4. 學生首次登入並更改密碼。

### 建課與發布

1. 教師建立課程及單元。
2. 上傳教材或建立題目。
3. 教師設定發布、截止、重試、抽題和答案公布規則。
4. 把班別加入課程或分享課程代碼。

### 編程與批改

1. 學生開啟編程題並自動載入起始程式碼。
2. 程式碼定時自動儲存。
3. 執行請求進入隔離執行佇列。
4. 回傳標準輸出、錯誤及資源用量。
5. 提交時執行公開及隱藏測試並計分。
6. 學生立即看到允許公開的結果；教師看到完整歷程。

### AI 提示

1. 平台整理題目、學生程式、錯誤和已用提示，不附帶不必要身份資料。
2. 檢查管理員政策和學生剩餘限額。
3. 透過供應商介面呼叫指定模型。
4. 保存用量和對話（如已啟用），回傳符合提示層級的回應。

## 3. 建議技術架構

- Web 應用：React／TypeScript 的響應式介面，伺服器端執行登入、權限、資料和 AI 代理。
- 關聯資料：MVP 使用 SQLite；正式校內部署可在需要時遷移至 PostgreSQL。
- 檔案：本地部署以具名資料卷保存，上線時可改用 S3 相容物件儲存。
- Python 執行器：獨立服務與 Web 應用分離，無外網、唯讀基礎映像、臨時工作目錄和嚴格資源限制。
- 背景工作：教材轉換、AI 生成、電郵、報表和備份使用工作佇列，不阻塞網頁請求。
- AI 供應商層：以統一介面連接不同供應商，金鑰只存在伺服器端。
- 本地部署：Docker Compose；服務及資料映像須支援 Apple Silicon。

## 5. 權限邊界

- 所有資料查詢先套用使用者角色與班別／課程範圍。
- 學生提交、AI 對話、檔案和成績只能由本人及獲授權教師查看。
- 隱藏測試只在執行器及教師介面出現，不送至學生瀏覽器。
- 教師草稿、標準答案和未到公布時間的內容不送至學生瀏覽器。
- 管理員金鑰、密碼雜湊和備份秘密不透過一般 API 回傳。

## 6. 原型優先頁面

第一個可操作原型以學生編程工作台為核心，同時提供角色切換來預覽教師與管理員儀表板。它應讓使用者直接看見平台最關鍵的差異：題目、程式編輯、測試回饋、AI 引導和課堂進度在同一個學習流程內運作。
